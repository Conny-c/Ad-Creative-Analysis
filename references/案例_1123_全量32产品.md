# 案例：2026-11-23 期全量（32 个竞品）

一次把口径从「TOP5」放大到「全量」的实战记录。数字、结论、以及踩到的返工点。

---

## 一、背景

| 项 | 值 |
|---|---|
| 口径 | ALL（37 个目录，32 个有新增） |
| 抓取 | 2094 条 |
| 素材总量 | 约 561 分钟 |
| 与上期差别 | 11-16 只做 TOP5（523 条），这期是全量，不可横向比 |

## 二、数字链（每一步去掉什么）

```
2094  抓取
 −564  md5 与历史台账重复（平台原样重发）
= 1530  账面「新增」
 −106  画面指纹：换编码/换分辨率的重传
 −157  音频指纹：同一条旁白、换了画面
= 1316  真正需要转写
 −349  判定为无人声/歌词/署名幻觉
= 967   有真口播
  −35  文本+花字+时长三层合并
= 932   唯一口播段（全部翻译）
```

**结论：账面新增 1530，真实内容量 1316，需要翻译的只有 932。**
抓取量 ≠ 工作量，中间的 40% 是重复。

## 三、四条结论（可执行）

1. **阿拉伯语区是这期最大的单块流量（164 条，11%），而且极省。**
   soulchill 一条阿语钩子「كون صداقات لديها نفس اهتماماتك」（交个同兴趣的朋友）**复投 35 条**，
   HaNI 另一条 14 条。做法是「一句话文案 × 换人换场景」——进这个市场不需要新脚本，复制这个模式就够。

2. **AI 生成动画 81 条（5.3%），比上期 TOP5（8 条）明显成规模。**
   AI 凭证确认 11 条，其余靠画质判断。真人的成本线正在被压。

3. **39% 的素材前 3 秒看不到产品，但 49% 结尾是下载引导。**
   「先藏产品 + 结尾硬落版」是这批的主流结构，与上期 TOP5 的结论一致，全量口径下更清楚。

4. **几家在刷条数：** EleLive 49→17（−65%）、Kitty 50→16（−68%）、Voice Pococha 50→21（−58%）、
   Wave 49→24（−51%）。同一支片子反复重传，**做竞品判断时别被账面条数骗了。**

## 四、返工点（下一期直接避开）

| 问题 | 现象 | 根因 | 处理 |
|---|---|---|---|
| bat 闪退 | 双击窗口一闪就关，报 `'ause' 不是内部命令` | 全部 .bat 是 LF 换行，cmd 解析错位 | 11 个 bat 全转 CRLF |
| 周更跑不动 | `PermissionError: D:\...\video-analysis` | 5 个脚本硬编码旧路径 | 改走 `SUGO_WORK` / 脚本位置 |
| 转写只有 1.1x 实时 | 1316 条要 5.4 小时 | 0–4 字的纯音乐素材也在跑关 VAD 复查，等于跑两遍 | 复查条件收窄到 5–19 字 → 8.5x |
| 第一版 xlsx 56MB | 打开极慢 | 1530 张印相用 440px/q72 | 压到 360px/q55 → 30MB |
| 去重量估高了 | 以为能省一半翻译量 | 音频查重已经在上游把真重复合掉了，剩下的是真不同录音 | 预估时先扣掉上游查重 |

## 六、下一期怎么更快

有 `voice_ledger.csv` 之后，同样的抓取量：

1. md5 命中 → 直接继承（原样重传）
2. 音频指纹命中（Jaccard ≥0.75 + 时长差 <8%）→ 直接继承（换壳同声）
3. 都不命中才转写

按这期的重复率推，**实际转写 300–600 条，整期 1 小时内**。
