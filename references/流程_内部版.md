## 1. 目录与产物约定

```
<根目录>\
├─ <YYYY-MM-DD>\<产品>\*.mp4          原始素材（每周一个日期目录）
├─ list\                              下载清单（1-更新下载清单 产出）
├─ analysis\
│   ├─ tools\                         全部脚本（见第 5 节）
│   ├─ models\                        faster-whisper medium（工作区内，不进 HF 缓存）
│   ├─ assets\
│   │   ├─ sheets_<期号>\*.jpg        每次素材一张 6 帧印相（1200×840）
│   │   └─ _tmp\                      抽帧临时目录
│   ├─ data_<期号>\
│   │   ├─ probe.csv rhythm.json ai_signals.csv ai_visual_worklist.json
│   │   ├─ asr.json vo_class.json vo_zh.json vo_unique.json
│   │   ├─ audio\*.wav                16k 单声道音轨缓存（口播转录复用）
│   │   ├─ audio_dup.json dedupe_map.json
│   │   ├─ wl_<期号>.json / wl_<期号>_bNN.json   打标 worklist
│   │   ├─ labels\labels_bNN.json     打标结果
│   │   └─ zh\zh_bNN.json             译文结果
│   └─ out\
│       ├─ master_ledger.csv          【台账1】md5 技术台账（累积）
│       ├─ label_ledger.csv           【台账2】视觉打标台账（累积）
│       ├─ voice_ledger.csv           【台账3】语音+音频指纹台账（累积）
│       ├─ weekly_<期号>_新增.csv     本期新增清单（待打标）
│       ├─ 2026-MM-DD_竞品素材拆解表.xlsx
│       ├─ 2026-MM-DD_口播转录表.xlsx
│       └─ 2026-MM-DD_*小结.md
└─ *.bat                              双击入口
```

**命名**：素材文件名 = `<产品>_<来源>_<地区>_<8位哈希>.mp4`，`stem` 就是去掉扩展名的部分。
全流程的主键：`md5`（跨周唯一）、`product|stem`（单期内唯一）、`序号`（拆解表内 1..N，等于 weekly CSV 行序）。

## 2. 每周固定动作

### ① 采集

| 入口 | 作用 |
|---|---|
| `1-更新下载清单.bat` | 抓最新一期素材页，重建 `list\` |
| `2-查看有哪些可选.bat` | 只列不下载 |
| `3-挑选下载(交互).bat` | 按竞品挑 |
| `4-全部下载.bat` | 全下 |
| `0-每周一键(清单+下载+去重).bat` | 上面前四步 + 视频去重一次跑完 |

下载器会按 `cover + duration + 中间帧` 判重，重复的删掉并记到 `list\<日期>.csv`。

### ② 素材去重（采集层）

| 入口 | 判据 | 是否删除 |
|---|---|---|
| `5-去重体检.bat` | 跨格式同内容（容器/编码不同） | 只报告 |
| `7-按封面去重(仅报告).bat` | 封面 + 时长 + 中间帧 | 只报告（`-Apply` 才删） |
| `9-空间回收(仅报告).bat` | 跨周同内容 → 硬链接 | 只报告（`-Apply` 才做） |

> 这一层是**文件级**去重，管"同一支片子被下了两次"。
> 它挡不住"平台换编码重传"，那要靠第 ⑤ 步的音频指纹。

### ③ 周更技术分析 —— `8-竞品素材分析.bat`

双击后输期号（回车=今天）、范围（回车=TOP5 / `ALL` / 产品名）。内部跑 5 步：

| 步骤 | 脚本 | 产出 |
|---|---|---|
| 探针 | `probe.py` | 时长/画幅/码率/切点/md5 → `data_<期号>\probe.csv` |
| 印相 | `sheets.py` | 每条 6 帧拼图 → `assets\sheets_<期号>\*.jpg` |
| 节奏 | `rhythm.py` | 帧差密度 / RMS / 静音比 / 语音调制 → `rhythm.json` |
| AI 信号 | `ai_detect.py` | C2PA 凭证 + 平台 AIGC 标记 → `ai_signals.csv` |
| AI 候选 | `ai_candidates.py` | 按风险排序的复核清单 → `ai_visual_worklist.json` |

然后 `weekly.py` 与 `master_ledger.csv` 做 md5 差集：
→ `out\weekly_<期号>_新增.csv`（本期新增）+ 台账追加。

**完成标志**：出现 `本期 N 条，新增 M 条，历史 K 条` 和 `请按任意键继续`。
中途 `sheets.py` 会长时间无输出（多线程抽帧，只在结束时打印 `built/skipped/failed`），
想看进度就数 `assets\sheets_<期号>` 里的 jpg。

### ④ 视觉打标

```bash
python scripts\make_worklist.py --csv out\weekly_<期号>_新增.csv \
    --out data_<期号>\wl_<期号>.json --batches 24
```

把 worklist 切成 N 批，每批交给一个子任务：看图（`read_image`）→ 按
`guides\label_guide_v2.md` 的枚举打标 → 写 `data_<期号>\labels\labels_bNN.json`。

自检：

```bash
python scripts\validate_labels.py     # 覆盖、idx/file 对齐、枚举越界、空值
```

出表：

```bash
python scripts\build_labels_xlsx.py --wl ... --labels ... --csv ... --out ...
```

→ `out\2026-MM-DD_竞品素材拆解表.xlsx`：`1_素材总表`（含印相缩略图）/ `2_文案库` / `3_汇总统计` / `4_产品画像`。

### ⑤ 口播转录

**先查重，再转写**（这一步最省时间）：

```bash
# 1) 音频指纹聚类（顺带把 16k wav 抽好，转写直接复用）
python scripts\audio_dup.py --csv out\weekly_<期号>_新增.csv \
    --audio data_<期号>\audio --out data_<期号>\audio_dup.json --extract --workers 16

# 2) 画面 + 音频两路合并，出「代表条清单」
python scripts\make_dedupe_list.py --csv out\weekly_<期号>_新增.csv \
    --audio-dup data_<期号>\audio_dup.json \
    --out-csv out\weekly_<期号>_新增_去重.csv --out-map data_<期号>\dedupe_map.json

# 3) 只转代表条（--ledger 会自动继承台账里已有的）
python scripts\asr_batch.py --csv out\weekly_<期号>_新增_去重.csv \
    --model <small 模型目录> --out data_<期号>\asr.json --audio data_<期号>\audio --threads 16

# 4) 二次判定：真口播 / 歌词 / 幻觉署名 / 无人声
python scripts\classify_vo.py --asr data_<期号>\asr.json --out data_<期号>\vo_class.json

# 5) 三层去重 → 唯一口播段
python scripts\build_vo_unique.py
```

人工覆盖：`classify_vo.py` 会读 `data_<期号>\vo_override.json`，明显判错的（日文乱码歌词、
`Beadaholique` 这类 Whisper 幻觉串、非本市场语种乱码）在这里按 key 改判。

翻译只译**唯一段**：`vo_unique.json` 切批 → 译 → `zh\zh_bNN.json` → 写回 `vo_zh.json`。

出表：`build_vo_xlsx.py`（11-16 版）/ `build_vo_1123.py`（带继承回填）→
`out\2026-MM-DD_口播转录表.xlsx`：`1_口播总表` / `2_口播库` / `3_无人声清单` / `4_统计` / `5_口播vs花字`。

### ⑥ 沉淀

```bash
python scripts\build_label_ledger.py     # → out\label_ledger.csv
python scripts\build_voice_ledger.py --all   # → out\voice_ledger.csv
```

## 3. 三张累积台账（增量机制的核心）

| 台账 | 主键 | 存什么 | 谁用 |
|---|---|---|---|
| `master_ledger.csv` | md5 | 技术指标 + 期号 | `weekly.py` 做新增差集 |
| `label_ledger.csv` | md5 | 12 个视觉标签 | 下周只打新增，不重标 |
| `voice_ledger.csv` | md5 + 音频指纹 | 口播原文/中文/判定/每秒 1 字节能量码 | `asr_batch --ledger` 直接继承 |

`asr_batch.py --ledger`（默认读 `out\voice_ledger.csv`）的继承顺序：

1. **md5 命中** → 原样重传，直接继承
2. **音频指纹命中**（shingle Jaccard ≥0.75 且时长差 <8%）→ 换编码/换文件的同一段声音，直接继承
3. 都不命中才真转

实测：1316 条里 214 条是被第 2 步提前合掉的；台账建立后用改过 md5 的同一条素材验证，正确返回 `继承(fp)`。
**下周预计只需转 300–600 条。**

## 4. 口径

### 什么算重复

| 层 | 判据 | 强度 |
|---|---|---|
| 文件 | md5 相同 | 最硬 |
| 画面 | 6 帧印相的 aHash+dHash 汉明距离 ≤18/256 | 强（换编码、重传） |
| 声音 | 音频指纹 shingle Jaccard ≥0.7 + 时长差 <8% | 强（同一条旁白，换画面） |
| 文案 | 花字相同 + 时长相同 + 文本相似度 ≥0.85 | 中（只有画面也相同才可靠，换画面时命中率约 43%） |

> 「花字 + 时长相同」**不能**单独当重复依据——花字是钩子，口播是展开，换演员时口播常被重写。

### 什么算有口播

`vo`（真口播）/ `none`（无人声）/ `lyric`（歌词，非文案）/ `credit`（片尾署名、`Thanks for watching!` 等幻觉）。
判据：字符数 ≥20 且不命中幻觉白名单；`small` 漏掉的用 medium 关 VAD 复查。

### 打标枚举

见 `guides\label_guide_v2.md`（形态/人物/语言/钩子/露出/CTA/规格/卖点/文案/拆解/置信），
AI 判定另见 `label_guide_ai.md`（只把 C2PA `trainedAlgorithmicMedia` 当定案）。

## 6. 已知坑（都踩过）

1. **.bat 必须 CRLF**。LF 换行会让 cmd 解析错位，双击一闪就关（`'ause' 不是内部命令` 就是这病）。改完 11 个 bat 全转 CRLF。
2. **工具脚本不许硬编码绝对路径**。`sheets.py` 等 5 个脚本原来写死 `D:\deepseek harness\video-analysis`，机器一换就 `PermissionError`。现在统一走 `SUGO_WORK` 或 `Path(__file__).parent.parent`。
3. **模型不要放 HF 缓存**。`C:\Users\...\.cache\huggingface` 在工作区外，沙箱只读，`large-v3` 卡在补下载上 10 分钟没动静。用 `fetch_model.py` 下到 `models\`。
4. **沙箱里跑不动抽帧脚本**。python 在 DSH 沙箱下 `chmod` 被拒，`TemporaryDirectory` 清理会抛 `PermissionError`；`ignore_cleanup_errors` 也压不住。要跑就用完整权限，或直接双击 bat（用户态不受限）。
5. **xlsx 别塞原图**。1530 张原图 ≈ 170MB；360px/q55 缩略图 ≈ 30MB；再小会看不清 6 帧里的字。
6. **`ALL` 口径会污染台账**。全量跑完，`master_ledger` 就有了全部素材，之后再跑 TOP5 会显示"新增 0"。想保留 TOP5 口径，跑 ALL 之前先备份 `weekly_<期号>_新增.csv`。
7. **md5 挡不住重传**。11-23 期 2094 条里，md5 已去重 564 条，但仍有 214 条是换壳的同内容——必须上音频/画面指纹。
8. **印相判不了口播**。6 帧图只能看画面，有没有人声必须 ASR。别根据形态猜。
9. **「花字+时长相同」不等于同一条口播**。实测换画面时只有 43% 的口播文本相似度 ≥0.85。
10. **抽帧阶段看起来像卡死**。`sheets.py` 全程无输出，2094 条约 8 分钟才打印一行汇总。
