# 竞品素材周更 · 一页说明

**一句话**：每周把竞品在投的短视频素材抓下来，出一份能直接改脚本的拆解表 + 一份口播稿全集。

---

## 每周拿到什么

| 产出 | 内容 |
|---|---|
| **素材拆解表** | 每条素材一行：形态 / 人物 / 场景 / 钩子 / 卖点 / CTA / 露出时点 / 规格 / 文案 / 一句话拆解 + 6 帧预览图 |
| **口播转录表** | 每条素材的口播原文 + 中文译文 + 是否有口播的判定 |
| **口径小结** | 本期结构变化、可复刻的结论、与上期的可比性说明 |
| **累积台账** | 下周只处理新增，不重复劳动 |

## 能回答什么

1. 竞品**在怎么拍**（形态、人物、场景、前 3 秒钩子）
2. **在说什么**（画面花字 + 口播全文，多语种）
3. **往哪儿导**（CTA 类型、产品界面第几秒出现）
4. **在用什么**（同一句文案换画面、同一条素材反复重传）

## 不能回答什么

**投放效果**。没有买量表，不做 install / CPI / 次留归因。这套只看「素材本身在讲什么」，不看「素材跑得好不好」。

## 一期大概多大

以最近一期全量（32 个竞品）为例：

```
抓取 2094 条 → md5 去重后 1530 条 → 换壳查重后实转 1316 条
→ 有真口播 967 条 → 去重后唯一口播 932 段（全部翻译）
```

耗时：周更体检 15 分钟 + 打标 40 分钟 + 转写 85 分钟 + 翻译 30 分钟 ≈ **3 小时**。
有台账之后同类规模的一期，转写量降到 300–600 条，**整体 1 小时内**。

## 三条边界（先说清楚）

1. **只看公开投放素材**，拿不到投放后台数据；报告里的"地区"是数据源标注，不等于真实投放配置。
2. **口播来自语音识别**，人名/品牌名有音转字误差，译文为逐段翻译，长句有压缩。
3. **结构分布受样本构成影响**：只做头部几家 vs 全量所有竞品，结论不可直接横向比较——每份小结里都会注明本期口径。

## 怎么提需求

| 你说 | 我们做 |
|---|---|
| 「跑一下这周的」 | 全量或 TOP5，按上次口径 |
| 「只看这几家」 | 指定产品，深度更高 |
| 「这期重点看 X」 | 在标准表之外补一页专项拆解 |
| 「口播不用全译」 | 只译复投与头部文案，其余给摘要 |
