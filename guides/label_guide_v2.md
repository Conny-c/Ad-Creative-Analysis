# 竞品买量素材 · 视觉标注规范 v2（多产品版）

## 你的输入
- `data/wl_multi.json`：每条含 `idx` / `file` / `product`（产品名）/ `sheet`（拼图路径）/ `duration` / `cuts` / `region` / `source`
- 每条素材对应 **一张 6 帧拼图**：3 列 × 2 行，按时间顺序；每帧下方标了时间点。
- 这些是**陌生人社交 / 语音房 / 直播 App 的买量素材**，观看场景是竖屏信息流，前 1-2 秒决定生死。
- 5 个产品：**Sugo**（语音房/聊天）、**Tango**（语音房/直播）、**Zili**（视频社交）、**Litmatch**（陌生人聊天）、**GRAVITY**（语音房，日本市场）。**注意：素材里出现的 App 界面可能是该产品本身，也可能是其投放的关联网站/落地页，按画面判断，不要预设。**

## 硬性要求
1. **只看图，不猜**。声音、口播内容不写。
2. 枚举字段必须**原样复制**给定字符串，不自创、不翻译。
3. 每条都要输出，**一条不漏**；`file` 与 `idx` 必须与 worklist 完全一致。
4. 一次只看一张图，看完立刻定标签，再处理下一条。
5. `summary` 要具体（谁、什么场景、做了什么、卖什么点），≤40 字。

## 字段与枚举

| 字段 | 含义 | 可选值 |
|---|---|---|
| `fmt` | 创意形态 | `真人单人出镜` `真人多人剧情` `手机屏幕录屏UGC` `图文卡点` `游戏界面演示` `直播切片` `AI生成动画` |
| `pop` | 出镜人物 | `年轻女性` `年轻男性` `男女双人` `多人` `无真人` |
| `lang` | 字幕/画面主语言 | `英语` `菲律宾语` `印尼语` `越南语` `泰语` `马来语` `西班牙语` `葡萄牙语` `法语` `德语` `土耳其语` `阿拉伯语` `日语` `韩语` `中文` `俄语` `印地语` `无字幕` `多语混合` |
| `hook` | 前 3 秒的抓手 | `真人开场直说` `利益/收益展示` `悬念提问` `冲突剧情` `产品界面直接开场` `颜值身材吸引` `纯文字提问` `素人自拍` |
| `prod` | 产品界面出现时机 | `前3秒` `3-10秒` `10秒后` `无产品界面` |
| `cta` | 结尾引导 | `品牌logo收尾` `下载安装引导` `立即开聊引导` `充值送礼引导` `无明确CTA` |
| `grade` | 制作规格 | `实拍精制` `实拍粗糙UGC` `纯UI加文字` `录屏拼接` |
| `selling` | 主打卖点（一个） | `交友聊天` `直播打赏` `语音房派对` `游戏互动` `赚钱福利` `附近的人` `视频匹配` `其他` |
| `text` | 画面最关键的 1-2 句原文（照抄，保留原语言；没有就空字符串） | 字符串 |
| `summary` | 一句话中文拆解，≤40 字 | 字符串 |
| `conf` | 置信度 | `0.9` / `0.7` / `0.5` |

## 输出
写到指定文件，JSON 结构：
```json
{"labels": [{"idx": 0, "file": "...", "fmt": "...", ...}]}
```
写完只回复一行 `done <路径> <条数>`，不要贴 JSON。
