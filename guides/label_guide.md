# Sugo 买量素材 · 视觉标注规范（v1）

## 你的输入
- `data/worklist.json`：每条含 `idx` / `file` / `sheet`（拼图绝对路径）/ `duration`（秒）/ `cuts`（场景切换点数量）/ `cuts_per_10s`
- 每条素材对应 **一张 6 帧拼图**：3 列 × 2 行，按时间顺序；每帧下方标了时间点（如 `1.2s`、`61.7s`）。
  拼图只截了 6 个瞬间，**不等于全片**；判断"过程/演变的"请结合 `duration` 与 `cuts` 推断，看不清就标 `uncertain`。
- 这是 **Sugo**（语音房 / 直播 / 陌生人社交 App）的竞品买量素材。观看场景是竖屏信息流（TikTok/Reels/Shorts），前 1-2 秒定生死。

## 硬性要求
1. **只看图，不猜**。画面里没有的信息（比如声音、口播内容）不要写。
2. 枚举字段必须用给定字符串，**原样复制**，不要自创、不要翻译。
3. 每条素材都要输出一行，**一条不漏**；file 必须与 worklist.json 完全一致（含中文、后缀）。
4. 一次只看一张图，看完立刻写结论，不要凭印象批量套模板。
5. 你的输出是给人做决策看的，`summary` 要具体（谁、在什么场景、做了什么、卖什么点），不要写"展示产品功能"这种空话。

## 字段与枚举

| 字段 | 含义 | 可选值 |
|---|---|---|
| `fmt` | 创意形态 | `真人单人出镜` `真人多人剧情` `手机屏幕录屏UGC` `图文卡点` `游戏界面演示` `直播切片` `AI生成动画` |
| `pop` | 出镜人物 | `年轻女性` `年轻男性` `男女双人` `多人` `无真人` |
| `lang` | 字幕/画面主语言 | `印尼语` `菲律宾语` `越南语` `英语` `泰语` `葡萄牙语` `无字幕` `多语混合` |
| `hook` | 前 3 秒的抓手 | `真人开场直说` `利益/收益展示` `悬念提问` `冲突剧情` `产品界面直接开场` `颜值身材吸引` `纯文字提问` `素人自拍` |
| `prod` | 产品界面出现时机 | `前3秒` `3-10秒` `10秒后` `无产品界面` |
| `cta` | 结尾引导 | `品牌logo收尾` `下载安装引导` `立即开聊引导` `充值送礼引导` `无明确CTA` |
| `grade` | 制作规格 | `实拍精制` `实拍粗糙UGC` `纯UI加文字` `录屏拼接` |
| `selling` | 主打卖点（一个） | `交友聊天` `直播打赏` `语音房派对` `游戏互动` `赚钱福利` `附近的人` `视频匹配` `其他` |
| `text` | 画面上最关键的 1-2 句原文文案（照抄，保留原语言；没有就空字符串） | 字符串 |
| `summary` | 一句话中文拆解，≤40 字 | 字符串 |
| `conf` | 置信度 | `0.9` / `0.7` / `0.5`（看不清/猜的用 0.5） |

## 输出
把结果写到指定文件，JSON 结构：
```json
{"labels": [{"idx": 0, "file": "...", "fmt": "...", ...}, ...]}
```
写完后只回复：`done <文件路径> <条数>`，不要把 JSON 贴回对话。
