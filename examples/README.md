# 结论输出案例

一期全量（2026-11-23，32 个竞品）的**交付物样本**。素材视频不进仓库，这里放的是「跑完之后长什么样」。

| 文件 | 是什么 | 看什么 |
|---|---|---|
| `2026-11-23_竞品素材拆解表_前25条.xlsx` | 拆解表前 25 行，带 6 帧印相缩略图 | 字段口径、印相怎么嵌、低置信怎么标 |
| `2026-11-23_竞品素材拆解表_全量.csv` | 1530 行全量数据（无图） | 全部字段与分布，可直接 diff |
| `2026-11-23_口播转录表_前25条.xlsx` | 口播表前 25 行，带印相 | 口播原文/译文/判定/来源（实转 vs 继承） |
| `2026-11-23_口播转录表_全量.csv` | 1530 行全量（无图） | 有无人声判定、语种、译文覆盖率 |
| `小结_拆解.md` | 素材层结论页 | 结构分布、产品画像、可直接执行的三条判断 |
| `小结_口播.md` | 口播层结论页 | 判定分布、查重收益、与上期口径对照 |
| `印相样例_01/02/03.jpg` | 一条素材的 6 帧拼图 | 3 列 × 2 行，帧下方是时间点 |
| `流程_对外版.docx` | 对外流程说明 | 方法、口径、边界 |

## 这期最关键的一组数字

```
2094 抓取 → 1530 账面新增 → 1316 真正要转写 → 967 有真口播 → 932 唯一口播段
```

抓取量 ≠ 工作量：中间约 40% 是换编码、换画面、重复上传，靠 md5 + 画面指纹 + 音频指纹三层剥掉。

## 结论长什么样

合格的结论必须能落到下一支脚本上，例如：

> soulchill 一条阿语钩子「كون صداقات لديها نفس اهتماماتك」复投 35 条，做法是「一句话文案 × 换人换场景」

不合格的结论：「画面清晰」「内容有趣」——无法执行。
